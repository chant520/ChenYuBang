## 范围

### 数据层（3.2 一并做，判分与落库同链路）

1. 复习队列查询：取 `mistake.state = 待复习` 的错题，按 `createdAt` 倒序（第 8.2 节，最近录入优先）；正文列读 `user_example` 事实源（第 8.1 节快照不变式）。
2. 单成语过滤：按 `mistake_idiom` 关联判定，命中任一勾选成语即入队（第 8.2 节版内修订）。
3. 判分：与 `user_example.myAnswer` 比对——本次所选不同＝答对、相同＝答错；每题判分后一行 `review_log`，同事务 `mistake.reviewCount` 加一、`lastReviewedAt` 刷新；`state` 不自动改。
4. 回归钉住：队列过滤 / 排序 / 回写 / state 不变四类状态机单测，钉住后做一次最小变异验证（恒绿不算钉住）。

### P11 复习队列（`review/queue`，全屏浮层）

1. 顶部进度「第 N 题 / 共 M 题」+「本轮范围」一行（全局＝「全部待复习」，单成语＝「只看『某成语』」）+ 关闭图标。
2. 题干与四个选项；选完立即判分，判分区文案逐字沿用 P10 重做串（`与首次作答一致（X）`／`与首次作答不同：首次 X，本次 Y`／`本题未记录你的首次作答，无法比对（本次选了 X）`）加口径说明一行，不显示「正确答案」、不渲染解析（诚实口径，第 8.2 节 2026-11-23 版内修订；无选项或首次作答未记录的题如实说明，不落 `review_log`、不计入正确数）。
3. 判分后出「下一题」；最后一题点「下一题」进 P12（IA 跳转表 20 的「自动进入」由该按钮承接，双端同口径）。
4. 退出二次确认（「退出会丢本轮进度」，确认后回栈底并丢弃本轮进度，跳转表 19 / 23）。
5. 空态：全局「今天没有待复习的错题」+ 回错题本；单成语「这个成语下没有待复习的错题」+ 回成语详情（第 5.4 节，单成语空态为直接进入后的兜底）。
6. P11 盖住底部标签，不保留中间状态（IA 浮层口径）。

### P12 复习小结（`review/summary`，全屏浮层）

1. 本轮范围一行、题量、答对数、答错数、涉及成语列表（每个可点进 P05，跳转表 20–26）；答错＝可比对已判分题数－答对数，不可比对题只计题量。
2. 主按钮按模式：「回错题本」回 P08 /「回成语详情」回 P05；各回各的栈底，队列状态清空。
3. 「再复习一轮」范围同本轮（单成语不扩大到全局）；返回回 P12，再退一次回栈底。
4. 0 题＝E17 兜底态（正常路径不可达，开发规范路由表）。
