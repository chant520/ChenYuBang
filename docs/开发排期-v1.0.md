# 成语记忆 App · 开发排期 v1.0

- 版本：v1.0（2026-11-17，主控产出）
- 定位：本文管**先做哪个、依赖谁、卡在哪**。功能范围以 `docs/产品功能规划-v1.4.md` 为准，页面结构以 `docs/信息架构-v1.2.md` 为准，视觉数值以 `docs/设计规范-v1.3.md` 为准，技术约定以 `docs/开发规范-v1.4.md` 为准。本文不新增任何功能或技术口径；与四件套冲突时一律以四件套为准。
- 拆解原则：先地基 → 先读后写 → 先本机后联网 → 数据模型冻结后才做备份。每个工作包标注功能点、落点页面/表、对应验收条（产品第六节 19 条）。
- 排序依据：依赖关系 + 验收闭环顺序，不做工期承诺（环境阻断未解，不编时间数字）。
