## 二、导航骨架

**底部主标签：4 个，顺序和名称都不变，固定为「成语 / 例题 / 错题 / 我的」。** 标签名沿用功能规划 3.5 节末尾的图标约定，不新增、不合并、不改名——即使「成语」标签的首屏已不是成语库。

| 序 | 主标签 | 落在哪一页 | 这个标签装什么 |
| --- | --- | --- | --- |
| ① | 成语 | P02 推荐首页 | 首屏是推荐首页；从它进成语库找成语、看成语详情、从成语翻到真题和我的错题 |
| ② | 例题 | P06 例题列表 | 按题库顺序看真题，进例题详情 |
| ③ | 错题 | P08 错题列表 | 我录入并标记为做错的题、按成语分组、从这里起全局复习 |
| ④ | 我的 | P13 我的 | 考试范围、备份与恢复、题库版本、清空数据 |

**关于页名与标签名不一致的一处说明**：底部标签①仍叫「成语」，但它的首屏页名写作「推荐」，二级页才叫「成语库」。这样做是为避免同一套导航里出现两个都叫「成语」的页面，让用户分不清哪一个是首屏。标签名不改，是因为它已被功能规划的图标约定锁定。

**不在主标签、作为二级页或浮层的功能**：成语库（P03，二级）、成语搜索（P04，全屏浮层）、某成语下的录入题（P09，二级）、考试范围设置（P14，二级）、备份与恢复（P15，二级）、题库版本与更新（P16，二级）、复习队列（P11，全屏浮层）、复习小结（P12，全屏浮层）、拍照录入整条链（P17–P21，全屏浮层逐屏推进）、导入方式选择与清空确认（P22、P23，弹层）。

**顶部区域的位置**
- 四个一级页顶部统一是「左边页面标题 + 右边该页自己的小图标」。P02 推荐首页右上角是搜索（此处用 SVG 矢量图标），P06 右上角是搜索的预留位，P08 右上角是「拍照录入题库」主按钮（此处用 SVG 矢量图标），P13 右上角不放图标。
- 二级页顶部统一是「左返回（此处用 SVG 矢量图标）+ 页名 + 右侧该页的上下文操作」。P03 成语库右侧是搜索，P10 录入题详情右侧是编辑与删除。
- 全屏浮层顶部只保留「关闭/取消」或「第几步」，不出现底部标签。
- 顶部区域不承担导航职责，导航只靠底部四个标签，避免两套导航打架。

**全局入口（拍照按钮）的位置**：右下角常驻悬浮按钮（此处用 SVG 矢量图标），**只出现在四个主标签页**：P02、P06、P08、P13。二级页、设置页、详情页一律不出现。页面有底部操作条时与之错开，与列表最后一条错开。P08 顶部另有一个「拍照录入题库」主按钮，与悬浮按钮是同一个入口。

**层级：视觉上仍是 3 层，没有第 4 层；但页面栈比 v1.0 多叠一层。**

- 第 1 层（一级）：P02 推荐首页、P06 例题列表、P08 错题列表、P13 我的——四个底部标签的首屏。
- 第 2 层（二级）：P03 成语库、P05 成语详情、P07 例题详情、P09 某成语下的录入题、P10 录入题详情、P14、P15、P16——都带返回、都盖住底部标签以外只有一屏。
- 第 3 层（浮层与弹层）：P04、P11、P12、P17–P21、P22、P23。
- P01 是启动页，不进导航，完成即从页面栈里移除，返回键不会回到它。

因为新增了推荐首页，成语链路从「二级页起步」变成「经成语库再进详情」，**常态最深的一条链是 4 屏：P02 推荐首页 → P03 成语库 → P05 成语详情 → P07 例题详情**。这 4 屏在视觉上仍分属一级与二级两个层次，不是新增了第 4 层；用户感知到的是「往回退四次回到首页」，不是「页面越叠越小」。

三条必须说清的例外，否则设计师会画错：
1. **成语详情与例题详情互跳会压栈。** 从 P07 点题干里的成语进 P05，再从 P05 的相关真题点回 P07，屏幕上始终是二级页，但页面栈可以继续加深，返回一次退一屏。这是「返回原处」必须付的代价，视觉层级不变。
2. **拍照链路是单向的 5 屏向导，不按层级算。** P17 → P18 → P19 → P20 → P21 只往前推，中途任一步取消就回触发拍照的那一页，已拍的图和已改的字丢弃。
3. **复习队列的两种来源共用页面、不共用栈。** 全局队列的栈底是 P08，单成语队列的栈底是 P05；两者都盖住底部标签，退出后各自回到自己的栈底页。

**五个页面存在依据（避免被误读成给进阶功能开了页面）**
- P02 推荐首页存在，是因为用户已拍板成语标签首屏单独成一屏（决策A）；MVP 阶段它只承担「入口聚合 + 推荐区占位」，不承载任何进阶功能的内容。
- P03 成语库存在且降为二级，是因为 A1 是成语学习主入口，推荐首页在 MVP 没有内容可学，必须有一页承接浏览。
- P06 例题列表存在，是因为功能规划已把「例题」锁定为底部四标签之一；MVP 阶段它只做「列出真题 + 点进 P07」，承载 B1、B3 的入口；B4 筛选、B5 搜索、B6 做题判分、B7 标记在这页只留预留位。

- P12 复习小结存在，是因为功能规划验收标准第 13 条要求「过完一轮后题量、正确数、涉及成语列表显示与操作一致」，这三项必须有个页面承接；它承载 D3，D5 的额外收尾内容在这页只留预留位。

**题库自动拉取的触发不产生跳转，故不另立行**：每次进入 P03 成语库或 P06 例题列表时，系统自动尝试拉取题库一次（每次进入触发一次、不做后台定时拉取）。这个动作不改变页面栈、不改变当前页、不新开页面，用户看不出页面跳转；拉取过程中页面内容照常可读（内置包兜底）。失败后页面停在原处，恢复内置包、版本号不变，用户可到 P16 手动点「检查题库更新」重试。

### 4.3 拍照主链落点说明（对应第 27–34 条）

五个屏幕依次是：拍照/相册（P17）→ 裁切（P18）→ 识别结果（P19）→ 成语匹配与修正（P20）→ 保存成功（P21）。P20 除原有的成语候选、答案、错因、标签外，增加可选「我的答案 / 是否做错」标记（勾选做错才生成错题记录）；错因与自定义标签仅勾选做错时可填，未勾选时置灰；一道题可归属多个成语（修正页候选可勾选一条或多条，至少一条；保存后仍可在录入题详情增删），保存后在每个所属成语下均可找到。P21 成功文案为「已存入我的题库」；多条归属时「去成语详情」进已勾选中的第一条（按候选顺序，手动增补排末尾），其余归属可在成语库或录入题详情查看。五屏编号与先后关系不变。

**起点只有四个**：P02 推荐首页、P06 例题列表、P08 错题列表、P13 我的。四个页面里都是「点悬浮按钮一下进相机取景，按快门一下完成拍摄」，共两次点击。P08 另有一个顶部「拍照录入题库」主按钮，同样一次点击进相机。

**落点是 P21 这张结果屏，由用户从三个去处里选一个**：该成语详情（P05）、错题本（P08）、继续录下一题（P17）。不做「保存后自动跳某页」，因为用户下一件事可能是核对归类，也可能是接着录卷子上另一道题。

## 五、全局交互规则

### 5.1 返回行为

- **二级页返回，回到打开它的那一页，不是回首页。** 返回后原页面的滚动位置与已选条件一律不变。P07 点进来的 P05、P05 点进来的 P07，都按这个规则走。
- **返回栈逐屏退，成语链路比 v1.0 多退一层。** 常态最深链是 P02 → P03 → P05 → P07，从 P07 一路返回到 P02，要退三次；每退一次都回到上一屏的原位置与原状态。
- **互跳用压栈，不用覆盖。** 从 P07 点成语进 P05 时，新 P05 压入栈；返回一次退一屏，回到 P07 那道题的原位置，题目不重新加载、答案遮罩状态不变。连续互跳可以叠多层，返回一层层退，不用「回首页」兜底。
- **全屏浮层靠关闭退出。** P04 搜索、P11 复习队列用顶部关闭，P17–P20 用顶部返回或取消；关闭即回打开它的那一页，浮层内的中间状态不保留。
- **弹层点旁边就关，关了等于没发生。** P22、P23 必须点明确按钮才执行，点遮罩或取消不产生任何数据改动。
- **重做不是新页面。** P10 中只有标错的录入题才有重做态，是同一页的状态切换，返回仍回上一屏；未标错的录入题为普通详情，无重做态。
- **复习的两条链路各回各的栈底。** 全局队列退出回 P08，单成语队列退出回 P05，不互相串。
- **物理返回键、侧滑手势与页面返回按钮完全同效**，不出现「按钮能回、手势退出 App」的分叉。
- **拍照链路任一步取消，回到触发拍照的那一页**，已拍的图、已改的文字全部丢弃，不留半成品草稿。
- **底部主标签切换**：切走时记住当前标签的页面栈与滚动位置，切回来原位恢复；再点一次当前标签，回该标签首屏顶部（标签①的首屏是 P02 推荐首页，不是 P03 成语库）。

### 5.5 首次打开路径（按决策F 重写）

**实际顺序**：P01 启动页 → 引导块中考试范围已默认全选（国考 + 事业编勾选，省考勾选且省份默认全选）→ 用户可直接点「进入」或「跳过」，也可先改勾选再进 → P02 推荐首页。省份仅作省考内容的筛选维度，默认全选、可自行增减。

四条写死的规则：
1. **默认已选，不要求用户先做一次选择。** 三项默认处于勾选态，控件与 P14 考试范围设置是同一份数据，改任意一处另一处同步。
2. **「进入」不再置灰。** 无论勾了几项都能进；「跳过」与「进入」结果相同，都是沿用当前勾选状态进入。v1.0 的「至少勾一项才能进」这条限制取消。
3. **改不改范围都能进，落地页都是 P02 推荐首页**（不是成语库，成语库现在是二级页）。
4. **只在第一次打开出现引导块。** 之后启动只做极短展示，直接进 P02；用户要改范围，从 P13 我的 → P14 考试范围设置。

依据（都是功能依赖，不是视觉取舍）：
- E1 的说明写明考试范围决定成语库与例题库的可见内容，默认全选保证第一次进 P03 时列表不为空，验收标准第 1 条「按考试范围筛选后的成语列表」可直接判。
- A1 的三个浏览维度之一是「按考试范围」，P03 把它当默认维度用，范围为空的这层切换就失效——默认全选避免了第一天的空库。
- 允许跳过，是因为范围随时能在 P14 改，把「先做一次设置」变成进入门槛没有必要性。
