## 一、一句话产品定位

一款给考公考编考生用的「成语记忆 + 真题练习」工具——从一个成语能翻到考过它的真题，拍一张卷子上的照片就能把题录进自己的题库、归到对应的成语下面，不注册不登录，学习记录只存在自己手机里；题库随安装包内置一份真实内容作离线底座，联网只用在两件事上：更新题库、把备份存到自己的网盘。

## 二、核心用户与典型使用场景

**核心用户**

- 正在备考国考、省考、事业编的考生，手机是主要学习设备；教师编考生在后续版本覆盖。
- 学习时间碎：通勤、午休、睡前，一次能坐下来的时间通常只有十几分钟。
- 共同困扰：成语靠背词条，背完不知道真题怎么考；做完的卷子错题留在纸上，回头既找不到，也没法按知识点归类。

**典型使用场景**

| 场景 | 用户在做什么 | 用到的功能 |
| --- | --- | --- |
| 通勤路上 | 刷十几个成语，看释义和易错点 | 每日推荐、成语卡片、成语详情 |
| 做完一套言语理解 | 对着纸质卷拍照，把题一张张录进自己的题库；若确实做错，在修正页顺手标一下 | 拍照录入题库、OCR 识别、自动匹配成语、人工修正（可选标错） |
| 背某个成语时心里没底 | 想知道这个成语到底怎么考、答案选项怎么设坑 | 成语详情页的「相关真题」列表 |
| 做题时卡在一个成语 | 从题目里的成语点进去查释义 | 例题详情的成语跳转 |
| 考前一周 | 集中过一遍「我错过的成语」，不做新题 | 错题本按成语分组、错题复习队列 |
| 换新手机前 | 把学习记录导成一个文件，存到自己的网盘 | 备份导出、网盘另存、恢复导入 |

## 三、功能模块清单

功能点编号用于后文分层表引用。图标类元素一律标注「此处用 SVG 矢量图标」，不使用图标字体或字符符号。

### 3.1 成语学习（A）

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| A1 | 成语库浏览 | 按考试范围（首发为国考、省考、事业编）、拼音首字母、考频高低三个维度浏览全部收录成语；省考勾选时默认全选所有可选省份、省份仅作筛选维度（详见 E1）。 |
| A2 | 成语详情页 | 一屏内集中展示：读音、释义、出处、感情色彩（褒义/贬义/中性）、易错点（望文生义、对象误用等）、近义与反义辨析。 |
| A3 | 成语搜索 | 支持输入完整成语、单字、拼音或拼音首字母，边输边出结果。 |
| A4 | 成语关联真题与我的录入题区 | 成语详情页内同时列出两类：系统整理的「考过这个成语的真题」与「我在这个成语下录入的题」，两类在同一区块分区展示、可区分，点击进入对应详情。（核心机制①的入口）系统真题暂无时，该部分保留并显示「暂无真题，后续补充」，不隐藏。 |
| A5 | 成语关联我的录入题区 | 成语详情页显示「我的录入题 N」（N 为该成语下全部录入题数，含未标错），点进去能看到该成语下全部录入题，其中标错的以错题样式与标记体现；属核心机制②的入口。 |
| A6 | 学习状态标记 | 用户可把成语标为「未学 / 学过 / 已掌握」，作为自评，不做自动判定。 |
| A7 | 收藏夹 | 一键收藏重点成语，单独成列表，便于考前集中看。 |
| A8 | 成语卡片自测 | 卡片正面只给成语、背面给释义与易错点，手动翻面，用于遮答案自测。 |
| A9 | 每日推荐 | 按用户设定的考试范围每天推送一组成语，数量固定、可手动换一批。 |

### 3.2 例题检索（B）

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| B1 | 例题详情页 | 展示题干、四个选项、正确答案、一句解析、以及出处（年份、地区、考试类型、题型）。解析只说明「为什么选这项」，不逐项解释错误选项。 |
| B2 | 例题 → 成语反向跳转 | 题干或解析里出现的成语都可点击，进入该成语详情页。 |
| B3 | 一题多成语 | 一道真题允许同时关联多个成语（例如四个选项各考一个成语），每个成语下都能看到这道题。 |
| B4 | 例题列表与筛选 | 按考试类型（首发国考、省考、事业编）、年份、题型、是否做过筛选浏览全库例题。二期（进阶）扩展为筛选范围同时覆盖用户录入题（本版不做）。 |
| B5 | 例题搜索 | 按题干关键词或成语名搜索例题。二期（进阶）扩展为搜索范围同时覆盖用户录入题（本版不做）。 |
| B6 | 做题与判分 | 在 App 内选答案、立即判对错并展开解析。做题判分随二期（进阶），本版不做，故本版错题来源仅拍照时可选标错一种。 |
| B7 | 例题标记 | 标记「已做 / 未做 / 收藏」，供后续筛选。随二期（进阶），本版不做。 |

### 3.3 错题本（C）

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| C1 | 拍照录入题库 | 调起相机拍纸质卷上的题，或从相册选已有照片，录入用户自己的题库；录入的题不必然是错题。支持一次只处理一道题。 |
| C2 | 图片裁切与摆正 | 拍照后框选出这道题的范围，去掉邻题与无关边缘，提高识别准确率。 |
| C3 | 文字识别（OCR） | 把裁好的图片转成可编辑文字，自动拆成题干与选项两块。 |
| C4 | 成语自动识别与匹配 | 系统从识别出的文字里挑出成语，在成语库中匹配出候选，默认勾选最匹配的一项。 |
| C5 | 人工修正（含可选标错） | 用户可改关联成语（换一个、加一个、删一个）、修正识别错的文字、可选填写「我的答案」并勾选「是否做错」（勾为做错才生成错题记录，并可补填「我的错因」）、加自定义标签。识别有缺漏时逐字补齐文字，这是唯一兜底；不提供纯手打新建空白题。 |
| C6 | 错题列表 | 只显示已标记为「做错」的录入题，未标错的录入题不在此列（可在成语下 A4「我的录入题」中查看）；按成语分组、按录入时间倒序、按考试类型三种视图切换。 |
| C7 | 录入题详情与重做 | 打开某道标记为做错的录入题，遮住答案重做一遍，再对答案、看解析；重做只对标错题生效。 |
| C8 | 错题编辑与删除 | 随时改关联成语、改标签、补充笔记；也可删除误录的题。未标错的录入题为普通详情，同样按本项编辑与删除，不提供重做。 |
| C9 | 错题掌握状态 | 每题标「待复习 / 已掌握」，由用户手动切换，或由连续答对触发提示。 |

### 3.4 复习巩固（D）

## 五、学习闭环

三类数据是这样串起来的：成语是骨架，系统真题是成语的考法，用户录入题是「我自己收进来的考法」，其中标错的那一小部分才是错题。用户从成语库进入一个成语（A1/A2），看到它的释义与易错点，同一页往下就能同时看到考过它的系统真题和自己在成语下录入的题（A4）；遇到想收的题，就拍下来录入自己的题库（C1），系统识别出题里的成语并归到这个成语下（C4），用户确认或修正（C5），若确实做错则在修正页顺手标一下（C5）；此后这道录入题统一在该成语详情的「我的录入题」中可见（A5，显示该成语下全部录入题数），其中标错的那部分同时进错题本、按成语分组（C6）；复习时按成语成组地过自己的错题（D1），答对答错都记下来（D3），掌握了的就从待复习里退出（C9）。整个过程里，用户始终只在两个动作之间来回——「这个成语怎么考」和「我在这上面收录/错过什么」，而这两件事在两处页面（成语详情、错题本）都能互相点到位。没有这一步，成语库只是词典、错题本只是相册；有了这一步，用户每背一个成语都知道它的考法，每录入一道题都自动长回对应的知识点上，题库越用越贴身。

## 六、MVP 验收标准

按「能验、能判」的口径列出，只有全部达标才算 MVP 可交付。

**成语学习**

1. 从首页进入成语库，能看到按考试范围（国考、省考、事业编）筛选后的成语列表；省考勾选时默认全选所有可选省份、省考内容默认可见，用户增减所选省份即按省份筛选省考内容，不出现「未选省份」导致省考内容隐藏的异常态；滑动浏览不卡顿、不重复、不空白；列表中不出现教师编专属内容。
2. 任取一个成语打开详情，读音、释义、感情色彩、易错点、近义/反义五项信息齐全，无「暂无内容」占位。
3. 输入完整成语、单字、全拼、拼音首字母四种方式均能搜到目标成语；查无结果时给出明确提示而不是空白页。

**例题检索**

4. 在成语详情页的相关真题区，关联到真题的成语能看到题干、四个选项、答案、一句解析、出处齐全；同一区块同时展示「我在这个成语下录入的题」，两类来源分区、可区分；系统真题暂无时，该部分仍显示并给出「暂无真题，后续补充」，不出现空白或区块消失。
5. 在例题详情页点击题干中任一成语，能跳到该成语详情页，且从该页能返回原题。
6. 一道关联多个成语的真题，在每个关联成语下都能被查到。
7. 例题详情页的解析为一句「为什么选这项」，不出现四个选项逐项辨析的长文。

**错题本（拍照链路）**

8. 在四个主标签页（成语 / 例题 / 错题 / 我的）任一处点拍照按钮，两次点击内进入相机；二级页与详情页不设拍照入口，用户需先回到四个主标签页之一；拍照后可框选范围，框外内容不参与识别；拍照录入的题存入用户自己的题库，不必然是错题。
9. 拍照到出识别结果，普通室内光线下能完整拿到题干与四个选项的文字；识别有缺漏时，用户可逐字编辑补齐，且补完后能正常保存为一条录入题。
   > 实测状态（2026-11-17）：代理引擎 18/20＝90%（Windows 离线中文 OCR，2× 放大 + 版面重建），两张未通过的都是「整行漏识」、题本身完整。App 端侧引擎（PaddleOCR / Vision）的真机复测按用户 2026-11-17 拍板先搁置，后置到「功能开发完成之后」再进行，过程与限制见 `docs/OCR实测记录.md`；此项仍属待真机确认，不作达标结论。
10. 识别完成后页面直接给出系统匹配的成语候选，候选里包含正确答案项；用户增、删、改关联成语后保存，录入题正确存入自己的题库并落到对应成语下；修正页可填写「我的答案」并勾选「是否做错」，仅勾选做错的题生成错题记录。
11. 保存后的录入题存入我的题库；成语详情页的「我的录入题 N」中 N 为该成语下全部录入题数，点进去能看到该成语下全部录入题，其中标错的以错题样式与标记体现；标记做错的题才出现在错题列表中，按成语分组能找到它，在对应成语详情页也能看到它；未标错的题不进错题列表。
12. 标记做错的录入题（即错题）可重做：答案默认遮住，点开可见，能改关联成语与标签，能删除。

**复习与数据**

13. 复习队列中只出现「待复习」错题（即标记做错的录入题），过完一轮后正确数、题量、涉及成语列表显示与操作一致。
14. 全程无需注册、无需登录即可使用；关掉 App 再打开，成语学习记录、录入题与错题数据完整保留。
15. 断网时，随安装包内置的题库（离线底座）中的成语与例题可正常浏览，不出现空白页或加载失败页；连内置包也没有、且联网获取也失败时，界面上出现的是标注 TEST 的测试数据，不与真实题库混淆。
16. 备份导出后，文件能存到手机本地；在系统文件/分享面板中能把该文件另存到网盘；全程不出现登录账号的步骤。
17. 从手机本地或从网盘选中的备份文件能读回数据，覆盖与合并两种方式都由用户当场选择。
18. 一键清空数据后，录入题（含标错的错题）、收藏、学习状态归零，成语库与例题库本身不受影响。
19. 联网只发生在两处：①题库获取——每次进入成语库页或例题页都自动尝试拉取一次（每次进入触发一次，不做后台定时拉取）；拉取成功即更新题库，失败则回落随安装包内置的题库，此时版本号保持不变、界面给出可重试的提示，用户可在「我的－题库版本」（P16）手动点「检查题库更新」重试；连内置包也没有时才用测试数据 mock 兜底，此时 P16 版本号位置显示「测试数据（TEST）」、其下方写 mock 的实际条数，并注明「题库未获取成功」，mock 明确标注 TEST、不得冒充真实真题。②把备份文件另存到网盘时走系统文件面板。不做后台定时拉取、不建账号。核对全流程，拍照 OCR 全链路零联网，任何学习记录都不被上传，断网时上述以外的功能全部可用。

**「联网」与「免登录、数据存本机」的边界（本版明确写死）**

- 联网只出现在两处用途：一是获取/更新题库数据（随安装包内置一份真实题库作离线底座；每次进入成语库页或例题页都自动尝试拉取一次，每次进入触发一次、不做后台定时拉取；拉取成功即更新，失败回落内置包、版本号不变、可由用户手动点「检查题库更新」重试；连内置包也没有时才用标注 TEST 的 mock 兜底，P16 版本号位置显示「测试数据（TEST）」、其下方写 mock 的实际条数并注明「题库未获取成功」）；二是把备份文件另存到网盘（走手机系统的文件/分享面板，App 不接网盘账号、不读网盘列表以外的内容）。拍照 OCR 全链路零联网，不产生第三处联网点。
- 不引入任何账号体系：不注册、不登录、不绑定手机号，题库获取与备份外存都不需要身份；不做后台定时拉取——题库拉取的自动触发只发生在用户进入成语库页或例题页时，每进入一次触发一次拉取，不在后台、不定时触发。
- 不上传学习数据：错题、收藏、学习状态、答题记录始终只在本机；备份文件由用户自己决定存到哪里，App 不代传。题库的三个来源（随包内置、联网获取、mock）都不涉及学习数据上传。
- 断网时除上述两处外全部功能可用：随安装包内置的题库（离线底座）照常浏览；联网获取失败时同样回落这份内置包，版本号不变且可重试；只有在连内置包也没有时，才出现标注 TEST 的 mock，界面明确其为测试数据并注明「题库未获取成功」；拍照录入题库、错题复习、备份导出到手机本地都不依赖网络。
- 网盘备份不等于云同步：恢复动作由用户手动选文件触发，App 不做多端实时同步，也不做跨设备自动合并。
